# Проект Дашборд эффективности рекламных кампаний в мобильном приложении
## Бизнес-контекст

Компания разрабатывает мобильное приложение и активно привлекает пользователей через рекламные каналы. Аналитической команде необходимо оценивать эффективность рекламных кампаний, активность пользователей и их конверсию в покупки.

Для этого используются три таблицы:
- `pa_costs` - расходы на рекламу по каналам;
- `pa_sessions` - сессии пользователей, пришедших из рекламы;
- `pa_orders` - заказы и выручка.

## Цель проекта

Объединить данные о расходах, сессиях и заказах в единый датасет и построить дашборд в Apache Superset, который позволит заказчику оценивать эффективность рекламных каналов, путь пользователя в приложении и конверсию в покупки.


## Задачи проекта

- Создать единый комбинированный датасет на основе трёх исходных таблиц.
- Рассчитать и вынести в KPI-индикаторы ключевые метрики:
  - выручка (с динамикой MoM);
  - затраты на рекламу;
  - ROI = (Выручка − Затраты) / Затраты;
  - количество заказов;
  - конверсия в заказ;
  - среднее время сессии;
  - количество сессий.
- Определить общий доход компании и каналы его поступления.
- Построить дашборд с логичной структурой: финансовые → операционные → пользовательские метрики.
- Реализовать сравнение периодов PoP (period-over-period) для всех KPI.
- Настроить фильтры и вкладки под разные срезы анализа.

## Структура дашборда

### KPI-панель 

- **Финансовые метрики**: выручка, затраты, ROI.
- **Операционные метрики**: количество заказов, конверсия в заказ.
- **Пользовательские метрики**: количество клиентов, средняя длительность сессии.

Все KPI - с сравнением с предыдущим периодом (PoP).

### Вкладка «Тип рекламной кампании»

- **ROI по типу рекламы** - Line Chart.
- **Баланс: доходы и расходы по типу рекламы** - Bar Chart:
  - расходы - отрицательные значения (ниже оси X);
  - доходы - положительные значения (выше оси X).

### Вкладка «Рекламный канал»

- **Динамика клиентской базы по каналам** - Bar Chart.
- **ROI по каналам привлечения** - Line Chart.
- **Средняя длительность сессии по каналам** - Line Chart.

### Вкладка «Тип устройства»

- **Распределение клиентов по девайсам (Total)** - Pie Chart.
- **Количество клиентов (MAU) по девайсам** - Bar Chart.
- **DAU по девайсам** - Line Chart.

### Фильтры

- **Период** - дефолт: 2019-05-01 — 2020-05-01.
- **Гранулярность** - по умолчанию месяц (кроме MAU и DAU-чартов).
- **Тип рекламы**.
- **Рекламный канал**.
- **Тип устройства**.


## Стек технологий

- **Apache Superset** - построение дашборда и чартов.
- **PostgreSQL** - источник данных.
- **SQL** - объединение таблиц и расчёт метрик.
- **Markdown** - оформление документации.


# Ключевые результаты

- Собран единый датасет из трёх источников (расходы, сессии, заказы).
- Рассчитаны KPI: выручка, затраты, ROI, заказы, конверсия, среднее время сессии, количество сессий.
- Построен многостраничный дашборд с логикой «от общего к частному»: финансы → операции → пользователи.
- Реализовано сравнение периодов (PoP) и гибкая фильтрация по датам, каналам, типам рекламы и устройствам.
